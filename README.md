# Timor-Leste stunting evidence dashboard

This repository contains the standalone GitHub Pages dashboard on childhood
stunting in Timor-Leste, including national trends, municipal burden,
contributing factors, equity gaps, and response options.

Published URL: https://humaflo.github.io/timor-leste-stunting/

The single-page site is in `index.html`. Its interactive visualizations and
municipal comparisons run in the browser without a build step.
