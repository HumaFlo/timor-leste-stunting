# Timor-Leste stunting brief

This repository contains the standalone GitHub Pages site for the Timor-Leste
childhood stunting brief.

Published URL: https://humaflo.github.io/timor-leste-stunting/

The single-page site is in `index.html`. Feedback submissions use the configured
Formspree endpoint; successfully submitted responses are also stored in the
visitor's browser and can be exported there.
